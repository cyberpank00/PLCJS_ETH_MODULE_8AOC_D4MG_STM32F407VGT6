# Инструменты 8AOC — калибровка и конфигурирование по Modbus TCP

Два эквивалентных клиента для настройки и калибровки модуля 8AOC
(8× 0–20 mA выход, DAC80508 + XTR111):

- `calibrate.mjs` — Node.js 18+, без внешних npm-пакетов
- `calibrate.py` — Python 3.8+, только стандартная библиотека

Оба реализуют встроенный Modbus TCP клиент и одинаковый диалог.

## Зачем нужна калибровка

Модуль формирует ток `I = 10 × V_DAC / R_SET`, где `V_DAC = code/65535 × 2.5 В`,
`R_SET ≈ 1.1 kΩ`. Допуск `R_SET` (0.1 %), ошибка опоры ЦАП и смещение XTR111
снимаются поканальной линейной коррекцией уставки:

```
I_cmd = gain × I_set + offset        (mA)
```

Процедура: при нейтральных коэффициентах инструмент выставляет ≥ 2 уставки,
вы вводите ток, измеренный эталонным амперметром в петле, инструмент
аппроксимирует `I_meas = a·I_cmd + b` и сохраняет `gain = 1/a`,
`offset = −b/a`.

## Одноразовая запись (write-once) — читать перед калибровкой

Коэффициенты в регистрах `540 + ch×4` — **живой предпросмотр** (до
перезагрузки). Постоянное хранение — команда **COMMIT** (`HR131 = 0xCA00 | ch`),
которая программирует слот канала в отдельном секторе Flash и **блокирует его
навсегда**. Инструмент после расчёта спрашивает подтверждение — нужно набрать
слово `COMMIT`. Любой другой ответ оставляет предпросмотр без фиксации.

Разблокировать можно только аварийным стиранием всего сектора
(`HR132 = 0xC1A5` + удержание кнопки `FACT_RES`), см. README репозитория.

## Порядок калибровки одного канала

1. Включите в петлю канала эталонный амперметр (`AOn+` → амперметр → нагрузка
   → `GND_ISO`; нагрузка ≤ 500 Ω при 24 В петли).
2. Запустите:
   ```
   node calibrate.mjs calibrate --ch 0 --ip 192.168.1.14
   # или
   python calibrate.py calibrate --ch 0 --ip 192.168.1.14
   ```
3. Инструмент обнуляет коррекцию канала и просит уставку: введите, например,
   `4`, затем измеренное значение; повторите для `12` и `20`; `done`.
4. Инструмент вычислит `gain/offset`, покажет невязку, запишет коэффициенты
   как предпросмотр и вернёт прежнюю уставку.
5. Проверьте невязку; если устраивает — наберите `COMMIT`.

Во время калибровки канал включается принудительно; comms-loss не срабатывает,
пока инструмент подключён (запросы идут каждые ~0.5 с).

## Другие команды

```
# Статус: уставки, шкалы, командуемый ток, код ЦАП, режим потери связи, флаги, блокировки
node calibrate.mjs status
python calibrate.py status

# Уставка и конфигурация канала (сохраняются SAVE как значения при включении)
node calibrate.mjs set --ch 0 --ua 12000 --enable 1 --lo 4000 --hi 20000
python calibrate.py set --ch 1 --loss safe --safe 3600     # NAMUR fail-low при потере связи

# Перезапуск изолированной аналоговой части (DAC + расширитель + питание петли)
node calibrate.mjs cycle
```

Параметры по умолчанию: `--ip 192.168.1.14 --port 502 --unit 1`.
