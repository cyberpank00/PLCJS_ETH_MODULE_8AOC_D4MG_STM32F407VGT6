# PLCJS_ETH_MODULE_8AOC_D4MG_STM32F407VGT6

Firmware for the PLCJS Ethernet module with 8 analog current outputs
0–20 mA (4–20 mA NAMUR), based on `STM32F407VGT6`. **Sourcing** outputs: the
module powers the loop from an isolated 24 V supply.

Eight channels are generated by one 16-bit `DAC80508` and eight `XTR111` U/I
converters; status is published over `Modbus TCP`, settings and **power-on
setpoints** live in internal Flash, calibration in a separate write-once
sector. Comms-loss behaviour (HOLD / SAFE / OFF), main `STAT_LED` plus eight
per-channel LEDs, factory reset, OTA via the Ethernet bootloader.
Infrastructure (network, multi-client Modbus, settings, LED, bootloader,
write-once calibration, compact register map) is inherited from `8AIC`.

## Hardware

| Block | Description |
|---|---|
| MCU | `STM32F407VGT6`; Ethernet `KSZ8863` (RMII) |
| DAC | `DAC80508ZRTET` — 8×16-bit, internal 2.5 V reference, 0…2.5 V, zero at power-up |
| U/I converters | 8× `XTR111AIDGQR`, `R_SET = 1.1 kΩ 0.1 % 10 ppm` → `I = 10·V/R_SET`, 0…22.7 mA |
| XTR111 control/status | `MCP23S17` SPI GPIO expander: ON (output enable), EF (error flag) |
| Isolation | digital `CA-IS3741` / `CA-IS3722`; power `URB2424S-6WR3` with CTRL on the MCU |
| Loop supply | isolated 24 VDC; the DAC and the expander are powered from the same rail |

Pinout: SPI1 SCLK=PA5, MISO=PA6, MOSI=PB5. DAC_CS=PA12, MCP_CS=PD8,
PVD_CTRL=PB7. Channel LEDs AO0..7 = PB15, PB14, PB10, PE15, PE14, PE13, PE12,
PE11. STAT_LED=PE9, FACT_RES=PE10, ETHRST=PD11, ETHINT=PB1. SPI ~2.6 MHz, mode
switched per transaction (mode 1 for the DAC, mode 0 for the expander).

MCP23S17 (address 0): `GPA0/1` AO3 EF/ON, `GPA2/3` AO5, `GPA4/5` AO6, `GPA6/7`
AO7; `GPB0/1` AO4 ON/EF, `GPB2/3` AO2, `GPB4/5` AO1, `GPB6/7` AO0. EF is
open-drain with a 10 k pull-up, **low = fault**.

### Analog side bring-up

The DAC and the expander are on the isolated rail, so at start-up:
`PVD_CTRL → ON` → 150 ms → DAC80508 soft-reset + config (gain ×1, all outputs
0) → MCP23S17 config (all channels OFF) → power-on setpoints. If either device
stops answering (5 consecutive polls) the firmware power-cycles the rail (at
most once per 10 s) and re-initialises; the same can be triggered manually
with `HR118 = 0xA0FF`. All outputs are 0 mA for ~0.7 s during the cycle.

`PVD_CTRL` polarity (`PVD_CTRL_ON_LEVEL`, `main.h`) and the ON line polarity
(`MCP23S17_ON_ACTIVE_HIGH`, `mcp23s17.h`) are constants to be verified on the
board.

Channel LED: solid = enabled and output driven; off = disabled (or output
removed by comms-loss OFF); fast blink (5 Hz) = fault (XTR111 EF: open loop /
out of compliance / over-temperature; expander or DAC not responding; rail off).

## Setpoint and channel scale

Two ways to write a setpoint (the last write wins):
- `HR 0 + ch` — int16 `0..32767` = `[low … high]` threshold (default
  4000…20000 µA); negative clamps to low;
- `HR 48 + ch` — directly in µA, `0..22000`.

Setpoints apply within ≤ 10 ms; `SAVE` (HR117) stores the current setpoints
as **power-on values**.

## Comms-loss behaviour

When no Modbus client has sent a valid request for `HR100` (×100 ms, default
50 = 5 s; 0 = disabled), each channel applies its mode `HR 32 + ch`:

| Mode | Action |
|---|---|
| 0 HOLD (default) | keep the last setpoint |
| 1 SAFE | output `HR 40 + ch` µA (e.g. 3600 NAMUR fail-low, 21000 fail-high) |
| 2 OFF | remove the output (0 mA, XTR111 off) |

Setpoints are restored automatically when a request arrives. The timer runs
from boot, so a master that never connects also triggers the safe state.

## Calibration

Per-channel linear correction `I_cmd = gain × I_set + offset`: with neutral
coefficients the tool commands setpoints, you measure the loop current with a
reference ammeter, the tool fits and writes the coefficients. Then
**write-once COMMIT** (`HR131 = 0xCA00 | ch`), 8 slots, status in `IR127`;
emergency erase `HR132 = 0xC1A5` + hold `FACT_RES` 3 s. See
[tools/README.md](tools/README.md).

## Modbus register map

Floats are float32, **high word first**. Multi-channel quantities are grouped
by quantity: 8 consecutive registers (or pairs) = channels 0..7.

### Compact block — Holding Registers (FC03/06/16), 0..55

| Reg | Description |
|---|---|
| 0..7 | **setpoint, int16 (RW)**: `0..32767` = `[low … high]` threshold |
| 8..15 | scale low threshold, µA (default 4000; 0..22000, < high) |
| 16..23 | scale high threshold, µA (default 20000; ≤ 22000, > low) |
| 24..31 | enabled (0/1, default 1) |
| 32..39 | comms-loss mode: 0 HOLD, 1 SAFE, 2 OFF |
| 40..47 | comms-loss safe value, µA (default 0) |
| 48..55 | **setpoint, µA (RW)**, 0..22000 |

### Status — Input Registers (FC04), 300..333

| Reg | Type | Description |
|---|---|---|
| 300..315 | float32 ×8 | commanded current, mA (0 when the output is off; includes the comms-loss substitution) |
| 316..323 | u16 ×8 | flags: bit0 enabled, bit1 output on, bit2 fault, bit3 comms-loss; bits15..8 fault code (1 XTR111 EF, 2 expander dead, 3 DAC dead, 4 rail off) |
| 324..331 | u16 ×8 | DAC code 0..65535 |
| 332 | u16 | loop rail on (0/1) |
| 333 | u16 | comms-loss active (0/1) |

Global: `120` fw major, `121` fw minor, `122/123` uptime s, `125` module id
(`0x08A0`), `126` MCU temperature (signed 0.1 °C), `127` calibration lock mask.

### Global settings — Holding Registers

| Reg | Description |
|---|---|
| 100 | comms-loss timeout, ×100 ms (0 = off, default 50) |
| 101 | LED mode (0/1/2) |
| 102 | Modbus slave id | 103 | Modbus TCP port |
| 104..107 | static IP | 108..111 | netmask | 112..115 | gateway |
| 116 | net mode: `0` static / `1` DHCP / `2` link-local (default `2`) |
| 117 | SAVE (`0xA5A5`) — settings + current setpoints as power-on values |
| 118 | REBOOT (`0xB00B`) / BOOTLOADER (`0xB007`) / KSZ8863 reset (`0x8863`) / **analog rail power-cycle (`0xA0FF`)** |
| 119 | FACTORY RESET (`0xDEAD`) | 130 | MCU temperature (RO) |
| 131 | CAL COMMIT (`0xCA00 \| ch`) | 132 | CAL ERASE ARM (`0xC1A5`) |
| 133 | EF / liveness poll period, ms (20..5000, default 100) |

Calibration coefficients (float32), base `540 + ch×4`: `+0..1` gain,
`+2..3` offset (mA). Nominals: `620..621` R_SET Ω (1100.0), `622..623` V_REF V
(2.5).

## Flash layout

| Region | Address | Size | Purpose |
|---|---:|---:|---|
| Bootloader | `0x08000000` | 128 KB | sectors 0-4 |
| Metadata | `0x08020000` | 128 KB | sector 5 |
| Application | `0x08040000` | 256 KB | sectors 6-7 (this firmware) |
| Staging | `0x08080000` | 256 KB | sectors 8-9 |
| Settings | `0x080C0000` | 128 KB | sector 10 |
| Calibration | `0x080E0000` | 128 KB | sector 11 (write-once) |

`SETTINGS_MAGIC = 0x08A04A57`, `SETTINGS_VERSION = 1`. Calibration: 8 slots,
magic `0xCA11B0A0`.

## Build

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

Identity — `Application/fw_header/fw_header.h`: `FW_PRODUCT_ID=0x504C0806`,
`FW_HW_REVISION=0x0101`, `FW_VERSION_VALUE=0x0101`.

## Flashing

```powershell
STM32_Programmer_CLI -c port=SWD -w build/Debug/PLCJS_ETH_MODULE_8AOC_D4MG_STM32F407VGT6.elf -v -rst
```

## Network defaults

Net mode `2` = link-local (factory): `169.254.<mac[4]>.<mac[5]>` /16 from the
UID, discoverable by MAC (UDP broadcast port `20556`). Static fallback: IP
`192.168.1.14`, mask `255.255.255.0`, gateway `192.168.1.1`. Modbus TCP port
`502` (up to 4 clients), unit id `1`.
